# YC Pitch Deck — No Fluff

## Rule 0: Fluff is a defect, not a style

If a slide cannot be read and understood in 20 seconds, delete it or cut it.
Investors spend ~2-3 minutes on a first pass. Clarity is the pitch.

## Structure: 10 slides, one per section, one investor question per slide

1. Title — What does this company do, for whom, in one sentence?
2. Problem — One problem, one buyer, one concrete cost or consequence.
3. Solution — What the product changes, in plain English, before any features.
4. Traction — Dated, labelled proof only: users, revenue, retention, pilots, growth. Date and source on the slide.
5. Additional metrics — One defined metric set that supports the story. Skip if it duplicates slide 4.
6. Why you / insight — What you know that others miss. One insight, not a feature list.
7. Business model — Buyer, price, billing cadence, what drives expansion or margin.
8. Market — Bottom-up from reachable buyers × price. Never "1% of a huge market" and never an unsourced TAM.
9. Team — One directly relevant accomplishment per founder. No degrees, exits, awards, or adjectives unless verified.
10. Ask — Amount, what it buys, milestone it unlocks in 12 months. If the amount is not set by the founder, write "Amount: to be set by founder" on the slide. Never invent it.

Use up to 3 slides for a section only when the evidence genuinely needs more room. Default is 1.

## Hard constraints

- Max 3 short lines per slide. Minimum 30pt body text.
- No stock photos of people. No decorative images. One brand image max, title slide only.
- No generic value cards. No "empowering / seamless / revolutionary / unlocking / supercharge / cutting-edge / next-generation / world-class / game-changing / delight".
- No invented numbers. Every number carries a date and a source label. Missing proof is written as a gap, in one line, not filled with vision copy.
- No technology as the sales pitch. Infrastructure, models, and containers belong in one line on the product slide, in value language, never as the headline.
- No claims about trials, credits, pricing, or partnerships unless verified and dated. Old snapshots are labelled "not current" with their date.
- Speaker notes carry the full slide text, so the deck is searchable and copyable.

## Verification checklist — run before delivery

- [ ] Every slide answers its one investor question in under 20 seconds?
- [ ] Every number dated and sourced? Any invented number removed?
- [ ] Banned-word scan clean?
- [ ] No stock people photos?
- [ ] Ask slide: amount present, or explicitly "to be set by founder"?
- [ ] Traction gap stated plainly if proof is weak, not hidden?

If any check fails, the deck is not ready. Fix it, do not explain it away.
