# Stocks Dip Alert

Daily check, after the US close, for a correction in the watchlist. Notify only when something dropped — never report tickers that did not drop.

## Watchlist

VOO, QQQ, GOOG, PLTR, AVGO, NVDA, META, MSFT, AMZN, COIN, ASML, BRK.B, TSLA, MRVL, URNM, CRCL, NEM, XLE, RSP — 19 tickers (Nov 15, 2026 — critic: the skill listed 13 while the run covered 19; MRVL, URNM, CRCL, NEM, XLE, RSP were covered but not listed).

## Use the current price

Always use the CURRENT price — the price the user just stated in chat, or the latest live price pulled in this run. Never use a stale close (e.g. the Nov 9, 2026 close) as today's price. If the user says "current price is $167", that is the price for the calculation, the % down, and the days-wiped-out lookback — use $167, not $178.67.

Follow the `smart-money-signals` skill — it is the canonical copy of every source, form, website, lag and price rule (insiders Form 4, congress PTR, 13F, options unusual activity, prices, FPE/PEG, momentum, company reports). Do not duplicate its rules here; if a rule changes, change it there.

## Daily run

Run every morning, ~08:48 WITA (Asia/Makassar), after the US close.

Each run:
- Pull the latest regular-session closes for each ticker, and their 52-week highs (with dates), from a live source (Finnhub via search, or the exchange / TradingView). Verify each price with the date; never reuse yesterday's price. Pull options chains after the close, when live quotes exist — pre-market pulls are empty.
- Compute % down from the 52-week high: (high - price) / high.
- Compute days of growth wiped out: calendar days back from today to the FIRST time today's price was reached, from daily candles — show the number AND the date, e.g. `471d (first reached 28 Jul 2025, verified 11 Nov 2026)`. That is the user's definition (Nov 11, 2026): the dip wipes out all growth since the price was first reached, not since the last time it was at that level. Never guess this number; find the first close at or above today's price in the candles. Compute the count from the two dates (today minus the first-reach date), never count days by hand. Nov 14, 2026: the file was 1 day short on URNM, CRCL and NEM against its own stated first-reach dates; corrected Nov 15.
- Notify ONLY when there is an action — a confident BUY or a SELL / TRIM (Nov 14, 2026 — user: the daily report already covers everything; this alert is only for what I have to act on). A level crossing alone is not an alert. A BUY alerts when the buy is confident: momentum turned up (price back above the 50-day + momentum Rising) + no INSIDER WARNING + no congressman exit + PEG cheap. A SELL / TRIM alerts when the thesis broke AND insiders or congress are exiting, or when a NEW insider warning appears for a watchlist ticker (a Form 4 sale filed in the last 24h that meets the warning rule), or when a tracked congressman exits a held position — even if the stock did not drop. If the verdict is HOLD, do not notify — no matter how far the stock fell. If nothing needs an action, say nothing.
- **Notify gate — check the verdict before notifying (Nov 15, 2026 — critic: the Nov 14 run labelled PLTR's cross below −20% and META's cross back above −20% as NOTIFY while both verdicts were HOLD).** A level crossing with a HOLD / DON'T ADD / WAIT verdict is recorded in the run file with its baseline update, never notified. Write the notify decision on every crossing row (NOTIFY + the BUY / SELL / TRIM verdict, or NO — HOLD) so the gate is checkable after the run.

**Plain English, no idioms (Nov 14, 2026 — user: "I don't understand this language"):** write every line in plain English. No idioms, no slang, no figures of speech. Never write "survived by a hair", "turn is back on", "flips", "by a hair", "knife's edge", or anything like them. Say it with numbers: the price, the 50-day average, the gap in $ and %, and what changes the decision. If a sentence needs an idiom to make sense, rewrite it without one. **No unexplained jargon (Nov 14, 2026 — user: "multiple compression and leadership discount" is fluff):** never write "multiple compression", "leadership discount", "de-rating", "re-rating", "multiple expansion", or any other finance jargon without explaining it in plain words with numbers. Write it like this: "the price fell 33% from $243.37 to $162.85, while earnings for this quarter are expected to grow about 90% from last year — the company earns more, but the stock costs less" and "the price is lower because the CEO resigned and no successor is named". Never print a Lynch class name (Stalwart, Fast Grower, Cyclical, Turnaround, Slow Grower, Asset Play) alone — write what the company sells in plain words instead. Every dropped row ends with a clear action line — "Action: ..." — what to do, how many shares, at what price. **Options glossary, under the alert every run it uses options words (Nov 14, 2026 — user: explain straddle / breakeven / call wall every time):** one short block, plain words — "Straddle = the price of a call + a put at the same strike; it shows how far the market expects the price to move by that date. Breakevens = the low and high prices the stock must reach for the straddle buyer to break even. Call wall = the strike with the most open call contracts; it acts as a top limit. Put wall = the strike with the most open put contracts; it acts as a floor. Max pain = the price where the most options expire worthless."

## Report format — only what dropped

Show ONLY the tickers that dropped to a level — one row per dropped ticker, no rows for tickers that did not drop.

`Ticker, -% down, -days of growth wiped out, reasoning, Recommendation`

**Print the FPE / PEG table every run** — one table, one row per watchlist stock (VOO, QQQ, and all 19 watchlist tickers), with columns: Ticker | Forward P/E (date, source) | Forward EPS growth % | PEG (= FPE ÷ growth, GAAP first, say so if non-GAAP) | Momentum (Rising / Falling / Flat + Strong / Weak) | Trend (Uptrend / Downtrend / Sideways + price vs 50-day %) | Verdict. Show it even for tickers that did not drop — the FPE / PEG table is not limited to dropped rows. For VOO / QQQ, use the index FPE / PEG (see Index entry check). **One verdict per row in this table too, with the entry price in the Verdict cell (Nov 15, 2026 — critic: the Nov 14 run's table used "WAIT / HOLD starter only", "HOLD / starter only", "BUY in tranches / HOLD" and "HOLD / BUY in tranches").** The Verdict cell carries one verdict (BUY / HOLD / TRIM / SELL / DON'T ADD / WAIT) plus the entry price in $ with its reason in a few words, or the sell levels for TRIM / SELL rows. **Every entry price names its reason and its basis (Nov 15, 2026 — critic):** the Verdict cell states the level the entry comes from and the numbers behind it — a dip level (put wall with its open interest, straddle low with the ATM strike, recent low with its date) or a turn level (the 50-day average it must cross above), and the FPE / PEG at that price with the basis named (published or calculated — the two disagree, so name it). **Momentum and trend every run (Nov 12, 2026 — user: show momentum and trend, not MACD numbers):** compute MACD internally for every watchlist stock (it is the momentum measure) but NEVER print the MACD line, signal, or histogram numbers in the report. Display two words per stock, with the date. **Momentum** — from the MACD histogram: Rising (histogram rising) / Falling (histogram falling) / Flat, qualified Strong / Weak by the histogram's slope and the MACD line's distance from zero. **Trend** — Uptrend (price above 50-day and MACD line above zero) / Downtrend (price below 50-day and MACD line below zero) / Sideways (the two disagree), with price vs 50-day % beside it. No RSI — excluded by the user Nov 11, 2026. Momentum is not a buy signal on its own — combine with the Lynch call.

Reasoning is one line on why it fell — earnings, guidance, NVDA / hyperscaler news — follow the `tradingview-news` skill, name the source and date.

Recommendation is one word (BUY / HOLD / TRIM / SELL / DON'T ADD) + one line, built from the `stocks-report` skill — all three views, in that order:
1. **Lynch** — multiple compression (earnings up, price down = buy) or earnings break (earnings down = don't buy)? GAAP PEG, 2-minute story still hold?
2. **Whale flow** — follow the `whale-options-flow` skill: are whales buying calls for a recovery, or buying puts / hedging? That sets the ceiling / floor.
3. **Filings — 13F / PTR / OGE** — 13F is institutional only (Berkshire, Bridgewater); Congress files PTR, Trump files OGE 278-T. Are they adding, holding, or exiting? Filing exit + fall = trim early. Filing add + fall = buy signal.
4. **Insiders — Form 4** — the company's own officers and directors, not politicians. Follow the `smart-money-signals` skill for the definition, the sources and the price rules.

## Buy trigger checklist — all three layers, not one (Nov 11, 2026)

A BUY recommendation needs all three layers. Cheap on PEG alone, with momentum still down, is WAIT, not BUY.
1. **Fundamentals:** PEG <1 on GAAP, forward P/E cheap vs history, earnings / guidance still holding, 2-minute story tellable.
2. **Momentum — buy when it turns up:** momentum turns Rising (histogram rising, MACD crossing above zero = stronger); price crosses above its 50-day SMA; ADX >25 = real trend; relative strength vs S&P turning positive over 1–3 months; up-move on rising volume; 12-1 month momentum turning positive. Do NOT recommend BUY while momentum is still Falling and price is below the 50-day, even if PEG is cheap.
3. **Confirmation:** whales buying calls for a recovery (not puts), filings with no exit (or adding), no insider warning, no new earnings break / guidance cut.
- One line: cheap on PEG + earnings hold + momentum turning up + price back above the 50-day = BUY. Cheap on PEG alone, momentum down, price below the 50-day = WAIT.

## Market drop vs single-stock drop (Nov 11, 2026)

- **Market down 15%+ (VOO / QQQ): buy the market, not a stock pick.** A broad -15% is usually multiple compression / fear, not one company's earnings breaking. Recommendation is BUY VOO / QQQ (in tranches: 1/3 now, 1/3 lower, 1/3 only if deeper), not a single stock.
- **One stock down 20–30% while the market is fine: that's a stock-pick moment.** Check why it fell first. If earnings / guidance still hold, it's Lynch-cheap — buy that individual stock. If earnings broke, don't buy it just because it's down.
- Apply this in the Recommendation column: a dropped VOO / QQQ row recommends the index; a dropped single stock row recommends that stock (or DON'T ADD / HOLD if its earnings broke).

If no ticker dropped to a level, say nothing. Never place an order.
